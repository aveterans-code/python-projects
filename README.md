  Calculates traffic violation fines based on speed limit.

    - Additional penalty for extreme speeding
    - Clear conditional logic

Example
  Speed Limit: 50 mph
  Clocked Speed: 62 mph
  Fine: $110.00

ch7ex11.py (Leap Year Checker)
  A Python script to determine if a given year is a leap year.
    - Implements complex leap year calculation logic
    - Handles century year exceptions
    - Demonstrates detailed conditional logic

Leap Year Rules
  - Divisible by 4
  - Not divisible by 100  OR
  - Divisible by 400

  -More comprehensive date validation
