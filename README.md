# python-projects
Contains python modules and sample output

ch5ex04.py (Acronym Builder)
  A Python script that generates acronyms from user-provided phrases.
    - Converts multi-word phrases to uppercase acronyms
    - Simple and intuitive user interface

Example
  Input: "Hurry Up And Wait"
  Output: HUAW

ch5ex11.py (Improved Chaos Program)
  Illustrates chaotic behavior using two different seed values.
    - Generates a table of chaotic function iterations
    - Compares two different initial seed values
    - Demonstrates mathematical chaos concept

king_program4.py (ASCII Number to Text Converter)
  Transforms a file of ASCII numeric codes into readable text.
    - Reads ASCII numeric values from a file
    - Converts numbers to corresponding characters
    - Useful for decoding encoded text

Example
  Input file: "84 104 101 32 90 101 110 32 111 102 32 80 121 116 104 111 110"
  Output: "The Zen of Python"
