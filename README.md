FINALS python-projects
Contains basic, entry-level, python modules and sample output

final01.py (Multiplication Table Generator) Creates a dynamic multiplication table based on user input.

- User-defined table dimensions
- Nested loop implementation
- Formatted output
- Displays row and column products

Example
Input: 12
Output: 
- Generates 12x12 multiplication table
- Shows row and column headers
- Calculates and displays each cell's product

final02.py (Word Processing Utility) A simple interactive word processing script.

- Interactive word input
- Counts total words entered
- Extracts first and last letters
- Converts words to uppercase

Example
Input: 
- pepsi
- yams
- tonic
- huito
- oreo
- nonpareil

Output:
6 Words were entered
p i PEPSI
y s YAMS
t c TONIC
h o HUITO
o o OREO
n l NONPAREIL

final03.py (Number Guessing Game) A classic number guessing game with hints.

- Generates random number between 1-100
- Provides 'higher' or 'lower' hints
- Interactive gameplay
- Continues until correct number is guessed

Gameplay
- Program selects a random number
- User makes guesses
- Game provides directional hints
- Game ends when correct number is guessed
