ch6ex12.py (List Sum Calculator)
  A simple Python script to calculate the sum of consecutive numbers.
    - Dynamic list generation
    - Sum calculation using custom function
    - Flexible input for list length

Example
Input: 17
Output: Sum of first 17 numbers is 153

ch6ex13.py (String to Number List Converter)
  Demonstrates type conversion within a list.
    - Converts list of string numbers to float
    - In-place list modification
    - Shows type casting techniques

Example
Input: ['12', '345', '15.34']
Output: [12.0, 345.0, 15.34]

king_program5.py (Number Squaring)
  A Python script that dynamically squares a list of numbers multiple times.
    - User-defined list length
    - In-place list modification
    - Demonstrates progressive exponential growth
    - Shows function parameter manipulation

Example
Input: 8 numbers
Initial List: [1, 2, 3, 4, 5, 6, 7, 8]
After 1st Iteration: [1, 4, 9, 16, 25, 36, 49, 64]
After 3rd Iteration: [1, 256, 6561, 65536, 390625, 1679616, 5764801, 16777216]
