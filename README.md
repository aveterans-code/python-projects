- List attendees
- Filter attendees by state
- Demonstrate inheritance (Attendee -> Speaker)

Key Techniques
- Class inheritance
- CSV file parsing
- Object-oriented design
- Dynamic object creation

Example
- Load attendees from CSV
- Display all attendees
- Show Maine-based attendees
- Highlight speakers with session details

dateconvert2.py (Date Formatting Utility) A simple utility to convert numeric dates to formatted string representations.

- Convert day, month, year numbers to multiple formats
- Use list-based month name mapping
- Demonstrate string formatting techniques

Example Inputs
Day: 25
Month: 12
Year: 2024

Example Outputs
- 12/25/2024
- December 25, 2024
