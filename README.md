# python-projects
Contains basic, entry-level, python modules and sample output

ch9exB.py (Random Number Generator)
  Simple utility for generating uniform random decimal numbers.
    - Generates specified number of random decimals
    - Uses Python's random module
    - Demonstrates basic random number generation

Example
Input: 5 numbers 
Output:
0.12345
0.67890
0.23456
...

ch9exC.py (Random Number Distribution Checker)
  Validates the uniformity of random number generation.
    - Tests distribution of random number generation
    - Calculates percentage occurrence of different values
    - Demonstrates statistical sampling techniques
    - Uses seeded random generation for reproducibility

Key Techniques
  - Random number generation
  - Statistical sampling
  - Percentage calculation
  - Uniform distribution testing

Example
Input: 10,000 samples
Output: Near-uniform distribution across 0-5 range

ch9ex07.py (Craps Game Simulation)
  A Monte Carlo simulation of the casino game Craps.
    - Simulates multiple Craps game scenarios
    - Calculates win probability
    - Demonstrates statistical sampling
    - Uses random number generation

Key Techniques
  - Probabilistic game simulation
  - Multiple function decomposition
  - Random number generation
  - Statistical analysis

Example
Input: 1000 game simulations
Output: Wins 47.60% of games
